# Brawl Lab

Public Ranked analytics, final-pick suggestions, map guides, counters and combos.

Live demo: https://brawl-lab-ten.vercel.app

This public-only source contains population aggregates and model code. It excludes private backend routes, personal histories, credentials and original repository history.

Run `npm ci`, `npm test`, `npm run build:public`. The GitHub refresh workflow remains gated until its server-side secrets and deployment protections are configured.

Unofficial fan project, not affiliated with or endorsed by Supercell.
